## 二、专业验证结果

### 2.1 主结果：错误避免端点

**端点定义**：答案是**完全错误的结论**——判定"代码没问题"、归咎于测试、
或编造出题目中不存在的机制。这正是 CHTD 设计所要迁移的能力（**错误恢复**）的反面。

| 组 | 失败数（15 题） |
| --- | ---: |
| 未微调基线（6 次独立判读） | **5**（范围 4–5） |
| 六个独立训练配置（CHTD + 5 个教师演示剂量） | **0–2** |

**联合检验**：在观测基线失败率（30%）下，六个独立配置**同时**达到该水平的概率
**≤ 3.4 × 10⁻⁹**；即使把基线真实失败率保守假设为 20%，仍为 **2.6 × 10⁻⁵**。

### 2.2 跨留出集合并

在三个独立留出集共 **57 题** 上合并（h3 为人工判读，h1/h2 为 LLM 判读）：

| 指标 | 基线 | 学生状态臂 |
| --- | ---: | ---: |
| 失败率 | **31.6%**（18/57） | **17.5%**（10/57） |
| 配对翻转 | — | 基线失败而学生臂通过 **12** 次；反向 **4** 次 |
| McNemar 精确检验 | — | **p = 0.077**（未达 0.05，方向三集合一致） |

### 2.3 种子稳定性（6 个种子）

| seed | 失败数 | 序数均值 |
| ---: | ---: | ---: |
| 0 | 2/15 | 1.600 |
| 1 | 1/15 | 1.533 |
| 2 | 3/15 | 1.467 |
| 3 | 2/15 | 1.600 |
| 4 | 1/15 | 1.400 |
| 5 | 2/15 | 1.600 |
| **汇总** | **均值 1.83** | **sd 0.084** |

**关键对比**：种子间标准差（0.084）比**同一 adapter 两次评估之间的漂移（0.333）小 4 倍**。
即：配方本身稳定；不稳定的从来是"单次小样本评估"。

### 2.4 判分器验证

| 指标 | 值 |
| --- | ---: |
| 短语门控 vs 作者 210 格账本 | 75.7% |
| 短语门控 vs 双读者一致面板（76 格） | 75.0% |
| **两位人类读者之间的一致率** | **84%**（76/90） |
| LLM 判读器 vs 人类面板（三级 / 二值） | **85% / 89%** |
| LLM 判读器在 210 格批量判读中的解析成功率 | **210/210** |

> **判分器精度不可能超过人-人一致率（84%）**——这是本项目主张"机器判读必须先通过人类一致性门控"
> 的依据，也是我们公开的测量局限。

### 2.5 统计功效

| 规模 | 最小可检测效应（MDE） |
| --- | ---: |
| 30 题/臂 | **26.6 个百分点**（8 题） |
| 48 题/臂 | 21.3 个百分点 |
| 达到 10 pp 检测力所需 | **227 题/臂** |
| 确认性实验所需（按观测效应） | **约 110 题/臂** |

> 此项决定了本项目早期的"无差异"结论**是关于检测下限的陈述，而非关于效应的陈述**。

### 2.6 剂量-响应

| 训练行数 | 失败数（15 题） |
| ---: | ---: |
| 0（基线） | 5 |
| 9（CHTD 学生状态） | 2 |
| 33 | 2 |
| 63 | 0–1（两次评估 0 与 1） |
| 83 | 1 |
| 93 | 1–2（两次评估 1 与 2） |

**结论**：33 行起曲线即平坦；15 题规模下无法分辨 33–93 行各档的差异。

### 2.7 独立对抗审查

全部数字经**独立审查代理**复算并提出质疑，审查意见公开于 PR #7–#11。其发现已并入记录，
包括一项我们接受并修正的口径问题（LLM 判读器分母在脚本与文档间不一致）；
其裁决为 **UPHELD**（测量可复现、结论成立），同时指出"0–3 pp 估计的置信区间过宽"这一有效挑战，
该挑战已写入结论文档。
