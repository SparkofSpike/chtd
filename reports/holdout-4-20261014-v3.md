## Integrity limits

These are exploratory phrase-gate counts, not semantic correctness scores. The checker matches literal phrases and identifiers in the final assistant answer. A false positive is present in the clean control seed 0 record for `h4-csv-bom-1`: the answer gives an incorrect explanation of `csv.reader` but passes the phrase gate. The task and symbol names alone can satisfy expected phrase groups for many instances. No DeepSeek judge endpoint was available in the accessible configuration, and no human adjudication was run.

The CHTD seed 1 ledger contains an extra `h4-form-decode-2` workspace with an unrecorded near-timeout session. The task was rerun and the second attempt is the scored row, so there were at least 49 actual attempts for 48 recorded task IDs. Its run metadata was reconstructed after the fact; this is not a clean one-attempt-per-task sweep.

The existing preregistration describes a different teacher-demo dose ladder (9/30/90-row arms) with blinded human correctness as the primary metric and says not to train or score before calibration. This seeded CHTD/control phrase-gate run deviated from it and must be treated as post hoc exploratory work. Existing run manifests also have null adapter artifact IDs and hashes, and the two CHTD seed 1 shards lack run manifests; adapter identity and seed provenance are therefore not independently pinned in the evaluation records.

Earlier runs copied the task `check.py` into model workspaces. Those runs are invalid and excluded from the table. Clean staging now omits `check.py` and a regression test verifies that. The invalid run directories are labelled in the private archive audit metadata.

## Conclusion

These records show only the stated phrase-gate outcomes. CHTD seed 0 (7/48) and seed 1 (38/48) differ sharply, and the paired result reverses direction by seed. This does not establish general CHTD superiority. A confirmatory comparison needs a prospective protocol matching the actual arms, immutable adapter hashes, one recorded attempt policy, and human or validated semantic grading.

The seed-0 answers are traced in `runs/holdout-4-20261014/README.md`: the adapter never lists the workspace, assumes a `src/` layout the fixtures do not have, and fails 96 of 109 `read` calls — all 7 passes are among the 13 sessions that ever read a file. The 29 "directory does not exist" answers report failed exploration, not a missing directory.
