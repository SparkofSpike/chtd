## Method and integrity notes

- Dataset: 48 held-out task instances covering 24 mechanisms, with zero task-ID overlap against the 44 training task IDs.
- All arms used the same Qwen3-4B-Instruct-2507 base family, minimal-rl preset, profile, and evaluation track. The two control and two CHTD adapters were trained from the same base with the matched LoRA recipe; each arm is evaluated on the same 48 task IDs.
- The holdout evaluator now stages implementation inputs but excludes each task's `check.py` from the model workspace. A regression test covers this behavior.
- Earlier runs that exposed `check.py` to the model are invalid and excluded from the table. Their raw records remain in the private experiment archive for audit and are labelled as invalid runs there.
- CHTD is a student-state, after-turn recovery method in this experiment; AGH forks only completed turns. It does not test branching before every within-turn decision.
- Score and record workspaces remain in the private `/mnt/proj/chtd-experiments` archive. No prompts, raw sessions, keys, or adapter weights are included in this Git report.
